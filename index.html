How it works
Designed for simplicity at scale
1

Officer submits a verified initiative

Any officer fills the submission form — or uses voice input — with a mandatory public reference URL. No login required. Submission is delivered via Google Apps Script to the master Google Sheet.

2

Editorial team reviews in Google Sheets

The TIGER team verifies the source URL and changes the Status field from "Pending" to "Approved" in the Moderation tab. No code required — any civil servant can do this.

3

GitHub automatically rebuilds the portal

A GitHub Actions workflow runs every 15 minutes, reads approved records from the Sheet, and republishes the updated static site to GitHub Pages.

4

Initiative appears in the public registry

Searchable in 8 Indian languages by state, domain, and stage. No server. No database. No maintenance team required. Total cost: ₹0 per month.
