Data integrity note

All 18 initiatives are drawn from publicly available government announcements, press releases, and verified news reports as of early 2025. No data is fabricated. Submit verified entries via the form to grow the registry.

How it works
Simple enough for any officer to maintain
1

Officer submits a verified initiative

Any government officer fills the form — or uses voice input — with a mandatory public reference URL. No login required. Submission travels via Google Apps Script to the master Google Sheet.

2

Editorial team reviews in Google Sheets

The TIGER team verifies the source URL and changes the Status cell from "Pending" to "Approved" in the Moderation tab. No code required.

3

GitHub automatically rebuilds the portal

A GitHub Actions workflow runs every 15 minutes, reads approved records from the Google Sheet JSON feed, and republishes the updated static site on GitHub Pages.

4

TIGER adds it to the registry

Searchable in 8 Indian languages by state, domain, and stage — visible to every officer across the country. No server. No database. No maintenance team.
